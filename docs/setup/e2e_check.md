## Расхождения с кодом, которые видны уже по исходникам (проверить в браузере)

- При 400 001 пользователь видит только код решения `review` (`r-decision` = `data.decision`).
  Причина «высокий пробег» в интерфейсе не выводится, и отличить её от review по LTV пользователь не может.
- ★ Второе место, где правило пробега видно пользователю: кнопка «Только рассчитать LTV» (`POST /api/ltv`) —
  она тоже идёт через `AssessmentService::assess`, поэтому при 400 001 тоже должна показать `review`.
  Плюс сообщение валидации `Пробег от 0 до 500000 км` при пробеге больше 500 000.
